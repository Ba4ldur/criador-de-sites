# Modelo de Perfil de Voz

Use exatamente esta estrutura ao construir um perfil de voz reutilizável:

```text
PERFIL DE VOZ
=============
Autor/Marca:
Objetivo:
Confiança (alta/média/baixa):

Fontes usadas
- fonte 1
- fonte 2
- fonte 3

Ritmo
- nota curta sobre tamanho das frases, cadência e fragmentação

Concisão
- quão densa ou explicativa é a escrita

Registro
- formal, informal ou situacional (você/o senhor, gírias, emojis)

Parênteses
- como são usados e como não são

Uso de perguntas
- raro, frequente, retórico, direto ou ausente

Estilo das afirmações
- como as afirmações são feitas, sustentadas e afiadas

Recursos preferidos
- recursos concretos que o autor usa

Recursos proibidos
- padrões específicos que o autor não usa

Regras de chamada para ação
- como, quando ou se termina com um pedido

Notas por canal
- Instagram:
- LinkedIn:
- WhatsApp:
- E-mail:
```

Orientações:

- Mantenha o perfil concreto e sustentado pelas fontes.
- Use tópicos curtos, não parágrafos.
- Cada recurso proibido deve ser observável nas fontes ou pedido explicitamente pelo usuário.
- Se as fontes se contradizem, aponte a divisão em vez de fazer uma média sem graça.
