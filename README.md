# Padrão Pleno Car: site

Landing page estática (HTML + CSS + JS, sem build). Para ver localmente, abra `index.html` no navegador.

## Estrutura
- `index.html`: página
- `css/style.css`: estilos (cores em `:root`)
- `js/main.js`: WhatsApp/Instagram (objeto `CONFIG` no topo), menu, carrossel, comparador antes/depois
- `img/`: fotos otimizadas (WebP) usadas no site
- `fonts/`: fonte Saira hospedada localmente (licença OFL)
- `originais/`: fotos enviadas, não usadas diretamente pelo site
